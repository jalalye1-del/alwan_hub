# Alwan Hub

تطبيق وسائط رقمية متعدد المنصات مبني باستخدام Flutter. يضم البث الإذاعي،
البرامج، البودكاست، الكتب الصوتية، الاستراحة، الألعاب، المكتبة والتسجيلات.

## التشغيل والتحقق

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء نسخة Android تجريبية:

```bash
flutter build apk --debug
```

ولبناء نسخة الويب:

```bash
flutter build web
```

## البنية

- `lib/core`: الصوت، التسجيل، التخزين، التوجيه، السمات والأدوات المشتركة.
- `lib/features`: ميزات التطبيق المستقلة وواجهاتها ومصادر بياناتها.
- `assets`: الصور والخط المستخدم داخل التطبيق.
- `test`: اختبارات الوحدة والواجهات.
- `docs`: قواعد التجاوب وعقد المحتوى القادم من لوحة التحكم.

## ملاحظات الإصدار

- بيانات البرامج والمحطات والبودكاست والكتب الحالية محلية/تجريبية، ويجب ربط
  `ContentRepository` بمصدر الإنتاج قبل اعتبار المحتوى متصلاً بلوحة تحكم فعلية.
- إعداد Android الحالي يوقّع بناء `release` بمفتاح التطوير. يجب إعداد مفتاح
  إصدار خاص وآمن قبل النشر في Google Play.
